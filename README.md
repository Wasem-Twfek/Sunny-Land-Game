# Sunny Land

A Unity/C# game-development project built to explore scene composition, gameplay scripting, and the Unity development workflow.

## Project focus

- Unity scene and asset organization
- C# gameplay scripting
- Player interaction and game logic
- 2D game development workflow
- Unity project configuration

## Technology

- Unity
- C#
- Unity Input / gameplay APIs
- Unity scene and asset pipeline

## Getting started

1. Install a compatible Unity editor version.
2. Clone the repository.
3. Open the repository folder from Unity Hub.
4. Let Unity regenerate its local Library and project metadata.
5. Open the main scene and press Play.

Unity-generated folders such as Library, Logs, Obj, and UserSettings are intentionally excluded from version control.

## Repository structure

~~~text
Assets/           # Scenes, scripts, prefabs, art and game assets
Packages/         # Unity package manifest
ProjectSettings/  # Project-level Unity configuration
README.md         # Project documentation
~~~
